# Wall Calendar: Privacy Policy

Wall Calendar is a personal, self-hosted family calendar display. It runs on a single computer in
our home and is not offered to the public.

**What it accesses.** With the household Google account's permission, it reads and creates events on
the calendars shared with that account, and reads the list of those calendars.

**Where data goes.** Calendar data is stored only on the home device that runs the app. It is not
sent to the developer or any third party, and it is not sold, shared or used for advertising.
Weather is fetched from Open-Meteo using the home's approximate location only.

**Removing access.** Revoke access at any time at https://myaccount.google.com/permissions. Deleting
the app's data file on the device removes all cached calendar data.

**Contact.** Use the support email listed on the app's Google consent screen.

Google API use complies with the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including its Limited Use requirements.
